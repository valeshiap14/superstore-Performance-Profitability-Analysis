# SuperStore Performance & Profitability Analysis

A Python data analysis and interactive dashboard project created to analyse SuperStore sales data, investigate profitability, identify patterns in discounts and regional performance, and present the results through an interactive Dash dashboard.

The project combines data cleaning, exploratory data analysis (EDA), statistical analysis, static visualisations, and interactive dashboard development.

## Project Objectives

The project focuses on the following business questions:

1. Which product sub-categories perform poorly in terms of profitability, and what factors such as discounts or geographical regions may contribute to this?

2. Which customer segments and geographical regions have the lowest profitability?

3. How are discount levels related to profitability, and when do higher discounts begin to negatively affect profit?

## Features

### Data Cleaning and Preparation

The project performs several data preparation tasks including:

- Loading the SuperStore dataset into a Pandas DataFrame
- Handling encoding issues using Latin-1 encoding
- Standardising column names
- Converting date columns into datetime format
- Converting numerical columns into numeric data types
- Checking missing values
- Checking duplicate records
- Detecting outliers
- Creating additional analytical columns

Additional columns include:

- `shipping_days`
- `profit_margin`
- `year_month`

## Interactive Dashboard

The project includes an interactive dashboard created using Python Dash.

The dashboard is called:

### SuperStore Performance & Profitability Dashboard

The dashboard allows users to analyse sales and profitability using interactive filters and visualisations.

## Dashboard Filters

Users can filter the data according to:

- Region
- Category
- Customer Segment
- Date Range

The user can also switch the regional performance chart between:

- Sales
- Profit

## Key Performance Indicators

The dashboard displays four main KPI cards:

- Total Sales
- Total Profit
- Average Profit Margin
- Number of Orders

These values automatically update when dashboard filters are changed.

## Dashboard Sections

### 1. Overview

The Overview section contains:

#### Sales vs Profit Scatter Plot

This chart shows the relationship between sales and profit.

- X-axis represents Sales
- Y-axis represents Profit
- Marker size represents Quantity
- Marker colour represents Customer Segment

The graph also provides additional information when the user hovers over a data point.

#### Monthly Sales Trend

This line chart displays sales performance over time.

The chart includes an interactive range slider that allows the user to examine different periods of the dataset.

---

### 2. Regional Analysis

This section contains:

#### Regional Performance

The chart compares performance between different regions.

The user can choose whether the chart displays:

- Total Sales
- Total Profit

#### Shipping Efficiency

This chart displays the average number of shipping days for each shipping method.

It helps identify differences in delivery efficiency between shipping modes.

---

### 3. Product & Segment Analysis

This section contains:

#### Segment Performance

The chart compares:

- Total Sales
- Total Profit

across the different customer segments.

The main customer segments include:

- Consumer
- Corporate
- Home Office

---

### 4. Static Visualisations

The dashboard also contains several static visualisations.

#### Profit Distribution

A histogram is used to display the distribution of profit values.

The vertical line at zero represents the break-even point.

#### Average Profit by Sub-Category

A horizontal bar chart compares the average profit generated by different product sub-categories.

Negative values are highlighted to make weaker product lines easier to identify.

#### Correlation Heatmap

The heatmap shows relationships between:

- Sales
- Quantity
- Discount
- Profit
